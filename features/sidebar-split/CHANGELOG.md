# Changelog

## 0.2.0 - 2026-11-21

- The collapsed icon rail gets the same split: a divider between panel and workspace icons, workspace icons always reachable, panel icons scroll when the window is short.

## 0.1.0 - 2026-11-21

- First release: the sidebar's panel list and Workspaces become two resizable panes with a draggable line between them. Each pane scrolls on its own, double-click hides the list, and the size is kept per browser.
